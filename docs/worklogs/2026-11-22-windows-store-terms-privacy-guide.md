# 2026-11-22 — Windows 0.5.0 Microsoft Store 배포 전 이용약관·개인정보·사용 안내 검토

- 상태: 문서 검토 중
- 대상: Windows용 비우자 0.5.0 Microsoft Store판

## 변경과 근거

Store판 [이용약관](../../STORE-EULA-v0.5.0.md), [개인정보 처리방침](../../STORE-PRIVACY-v0.5.0.md),
[사용 안내](../STORE-GUIDE.md)에 국문과 영문을 함께 실었다. 체험 중 앱을 열어 둔 경우와
만료 후 다시 실행하는 경우, 일회 구매와 환불 문의 절차, 기기 변경 시 다시 설치하는 방법을
설명했다. 개인정보 문서는 앱이 기기에서 처리하는 파일과 Microsoft의 Store 사용권 조회·판매
보고, 이용자가 선택한 문의 경로를 구분해 설명한다.

무료판 최상단 약관에는 기존 사용자가 무료판을 받을 때 적용되던 조건이 남아 있다. Store판 문서는
별도 주소에서 읽을 수 있도록 준비했다.

## 확인과 다음 순서

제품 정본과 공개 검토본 세 파일의 UTF-8 전체 바이트를 대조했다. 문서 안의 링크 77곳을
확인했다. 현재 변경을 포함하는 공개 저장소 경로는 검토본 파일에서 확인했고, 외부 주소
27개는 로그인하지 않은 상태에서 응답을 확인했다. Microsoft 주문 기록은 로그인 화면으로 연결된다.

검토가 끝나면 병합된 공개 원문과 제품 정본을 다시 대조한 뒤 Partner Center의 추가 사용 조건,
개인정보 및 지원 항목을 연결한다. 현재 단계는 문서 검토이며 Store 접수·인증·거래 검증은 후속 단계다.

## 업데이트 후 제외된 설정에 관한 보완

처리방침 제4절에 Windows 시작 안전 검사에서 제외된 설정 원문을 보관하는 위치와 수동 삭제 방법을 국문·영문으로 추가했다. 정상 설정에서는 사본을 만들지 않고, 같은 원문에는 기존 사본을 재사용한다. 작성 중 강제 종료로 임시 파일이 남을 수 있어 보관되는 내용과 정리 조건도 함께 설명했다.

사용 안내에는 사본을 텍스트로 검토하고 앱에서 허용되는 폴더와 규칙을 다시 설정하는 순서를 담았다. 검토 브랜치에서 제품 정본과 버전별 약관·처리방침·사용 안내의 전체 바이트를 다시 대조했다.
