# 2026-11-26 — Windows 0.5.0 구매 조건과 개인정보·구성요소 안내

- 상태: 공개 전 문서 검토 중
- 대상: Windows Microsoft Store판

개인별 30일 체험과 지역별 결제 직전 가격을 [이용약관](../../STORE-EULA-v0.5.0.md)에 담았다. [구매 안내](../STORE-GUIDE.md)에는 출시 초기 가격 계획과 이미 결제했을 때 추가 결제 없이 사용권을 확인하는 방법을 설명했다. [개인정보 처리방침](../../STORE-PRIVACY-v0.5.0.md)에 선택적 문의를 전달·보관하는 업체, 일반 문의의 삭제 절차·법정 보존 예외와 사용자가 설정한 외부 백업을 적었다.

고객이 보호된 설치 폴더를 열지 않아도 [0.5.0용 제3자 고지](../../windows-v0.5.0/THIRD-PARTY-NOTICES.txt)와 [원본 소스 안내](../../windows-v0.5.0/THIRD-PARTY-SOURCE.md)를 확인할 수 있도록 별도 경로를 준비했다. 고지·약관·처리방침·안내 5개 파일을 제품 정본과 바이트 단위로 대조했다. 무료판과 Mac판은 각자의 문서 경로를 유지한다.

운영자의 법률·개인정보 검토 후 공개 본문과 앱에서 열리는 텍스트를 다시 비교한다. 현재 단계는 문서 검토이며 Store 제출·판매 또는 가격 변경을 진행하지 않았다.
