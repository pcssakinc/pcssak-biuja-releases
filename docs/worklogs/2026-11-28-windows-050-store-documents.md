# 2026-11-28 — 윈도우 스토어판 0.5.0 문서 공개 준비

비공개 배포를 준비하는 사용자가 [구매 안내](../STORE-GUIDE.md)에서 [이용약관](../../STORE-EULA-v0.5.0.md), [개인정보처리방침](../../STORE-PRIVACY-v0.5.0.md), [제3자 고지 전문](../../windows-v0.5.0/THIRD-PARTY-NOTICES.txt), [구성요소 원본 소스](../../windows-v0.5.0/THIRD-PARTY-SOURCE.md)를 확인할 수 있다. 다섯 파일은 윈도우 배포 후보의 원문과 바이트 단위로 대조했다.

국문과 영문의 지원메일 안내에는 운영자의 일반 문의 삭제 절차, 전달 로그, 메일함과 암호화 백업의 처리 조건을 구분했다. 이 주소의 실제 처리 국가와 전달 로그 사본의 최종 파기 시점은 아직 확인 중이다. 구매 안내에는 30일 체험과 시장별 출시 가격 계획을 적었다. 앱의 스토어 인증·구매·환불·자동 업데이트 실측은 별도로 진행한다.
