# 2026-11-22 Mac App Store판 개인정보 처리방침 초안 갱신

## 1. 작업 기록

09:16 KST에 기존 공개 초안을 확인했다. 09:17 KST에 한국어와 영어 정책 전문을 Mac 앱에 넣을 문안과 대조했다.

## 2. 정정한 내용

[11월 15일 기록](2026-11-15-mac-store-privacy-v050.md)에 있던 문의 자료 보관 기간 3년은 당시 초안의 값이었다. 고객지원 운영 방식을 확인해 답변 후 문의 메일과 첨부 파일을 삭제한다는 내용으로 고쳤다.

## 3. 개선한 내용

지원 메일이 전달되고 처리되는 과정, Mac에 남는 자료와 문의 내용의 차이, Apple의 앱 구매 확인 과정에서 처리하는 정보를 국문과 영문에 함께 반영했다.

## 4. 확인 결과

[공개 검토용 정책 전문](../../MAC-STORE-PRIVACY-v0.5.0.md)과 앱에 넣을 한국어·영어 본문을 대조해 글자와 줄바꿈까지 일치함을 확인했다.

## 5. 다음 할 일

공개 전 최종 출시 앱의 동작과 문구를 다시 대조한다. 승인과 게시가 끝나면 최종 정책 주소에서 본문과 언어 이동 링크를 확인한다.

## 6. 보존 기록

11월 15일 기록은 당시 결정의 이력으로 보존했다. 이 변경은 Mac App Store판 정책 초안에 적용한다.
