# 2026-11-22 — Windows 0.5.0 설치 요건과 중단된 작업의 위치 안내

- 상태: 문서 검토 중

[Store 사용 안내](../STORE-GUIDE.md)에 Windows 10 22H2(빌드 19045) 및 Microsoft Edge WebView2 Runtime 111이라는 설치·실행 조건과 사용자가 빌드를 확인하는 방법을 국문·영문으로 기재했다. 복사·이동이 끊겼을 때 비우자에서 해당 기록을 찾는 방법, 내용 확인 전 원본과 작업 파일을 보관할 이유를 추가했다.

32비트·64비트 시험 패키지에 기록된 설치 하한, 앱의 실행 조건과 화면 문구를 확인하고 공개 초안을 제품 안내와 대조했다. 이 기록은 고객 안내 초안 검토에 해당한다. 실제 판매 상태·지원 범위는 해당 버전의 공식 배포 공지와 Microsoft Store 상품 페이지에서 확인한다.
