# 2026-11-15 — Store 0.5.0 개인정보 고지 범위 보완

- 상태: 완료
- 범위: 개인정보 문서만 갱신, 앱·설치본·Store 제출·유료배포 없음

## 변경과 근거

PCSSAK 자체 자동 오류 업로드 기능이 없다는 설명과 Microsoft WebView2 Runtime의 독립적인 진단을 구분했다. 필수·선택 진단과 Windows 동의 및 Runtime 설정에 따른 충돌 보고 가능성을 한영 같은 범위로 설명하고 Microsoft 공식 안내를 연결했다. 실제 사용자 파일 전송이나 개인정보 유출이 관측됐다는 뜻은 아니다.

기술 근거는 제품의 고정 wry0.55.1/webview2-com0.38.2 기본값과 [WebView2 개인정보 문서](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy), [Microsoft 개인정보처리방침](https://privacy.microsoft.com/privacystatement)이다. 런타임·보안 설정·권리·가격·상점 신원은 바꾸지 않았다.

## 확인과 보존

제품 정본과 LF 기준 전체 본문이 동일한 것을 대조했다. 기존 v0.2.0 문서·v0.1.x 무료판·바이너리·다운로드 링크를 보존한다. 새 개인정보 문서의 게시를 실제 계정 등록·상점 심사·거래 또는 프로그램 유료출고 완료로 표시하지 않는다. 병합 후 공개 원문을 다시 받아 제품 정본과 지문을 대조한다.
